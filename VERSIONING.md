# Versioning

The project currently identifies itself as `0.3.0` and remains experimental. There are no compatibility guarantees or stable release series. Before a first public release, the maintainer should publish a changelog entry and use Semantic Versioning: patch for compatible fixes, minor for backward-compatible features, and major for incompatible public API or data migrations. Do not advertise `1.0.0` until compatibility and support expectations are explicitly adopted.
