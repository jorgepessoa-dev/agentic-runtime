# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues. Use GitHub Private Vulnerability Reporting from the repository Security or Advisories page. If the private reporting option is unavailable, do not disclose details publicly; contact the repository owner through GitHub to request a private channel.

Include the affected version or commit, technical details and reproduction steps, impact, and an optional suggested mitigation. Do not include unrelated secrets or personal data.

## Supported versions

Until stable versioned releases are published, security support applies to the default branch and the latest tagged release, if any. The project has no guaranteed response-time SLA.
